BRIGHT FUTURES EDUCATION FOUNDATION WEBSITE — DEPLOYMENT NOTES

This ZIP is prepared for static hosting services such as Netlify Drop. The website file index.html is at the root of the ZIP.

BEFORE SHARING WIDELY
1. Add the foundation’s official email and phone/WhatsApp number to the Contact section. The current page explicitly shows reminders to replace these details.
2. The website describes the foundation as a proposed initiative. Keep that wording until registration is complete.
3. The contact form currently prepares a message in the visitor’s device; it is not a hosted inbox or donation-processing system. Test it and set up a real contact method before relying on it.
4. Do not publish student names, personal details, or photographs without appropriate permission.

QUICK PUBLISH STEPS
1. On a computer or phone browser, create/sign in to a Netlify account at https://app.netlify.com/ .
2. Open Netlify Drop at https://app.netlify.com/drop .
3. Upload this ZIP (or unzip it and upload the folder containing index.html).
4. Netlify should publish the static site and provide a temporary address ending in netlify.app. Save that address.
5. To use a custom domain, first register a domain through a registrar. Then, in the Netlify site dashboard, open Domain management / Add a domain and follow the displayed DNS instructions. DNS changes may take time to take effect.
